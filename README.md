# Mapa Conceitual — Bacharelado em Sistemas de Informação

Mapa conceitual/mental desenvolvido para apresentar a relação entre as áreas de conhecimento, disciplinas do curso de Bacharelado em Sistemas de Informação do IFMG — Campus Ouro Branco e suas possíveis trajetórias profissionais.

## Sobre o projeto

O objetivo do projeto é representar visualmente como diferentes disciplinas do curso contribuem para a formação em Sistemas de Informação e como elas podem se relacionar com diferentes possibilidades profissionais.

O mapa foi construído como uma **rede de conhecimentos**, e não como uma sequência obrigatória de disciplinas. Uma mesma disciplina pode contribuir para diferentes áreas e carreiras.

Ao selecionar uma possibilidade profissional no mapa, as disciplinas relacionadas são destacadas para facilitar a visualização de possíveis caminhos de formação.

> As relações apresentadas representam possíveis trajetórias profissionais e não significam que determinadas disciplinas sejam requisitos obrigatórios para exercer uma profissão.

## Estrutura do mapa

O mapa está organizado nas seguintes áreas:

* **Programação e Algoritmos**
* **Dados e Inteligência**
* **Matemática e Fundamentos**
* **Engenharia de Software**
* **Infraestrutura e Redes**
* **Gestão e Negócios**
* **Formação Complementar, Profissional e Social**

Entre as disciplinas representadas estão, por exemplo:

* Introdução à Programação
* Algoritmos e Estrutura de Dados I e II
* Programação Orientada a Objetos I e II
* Programação Web
* Banco de Dados I
* Probabilidade e Estatística
* Sistemas de Apoio à Decisão
* Inteligência Artificial
* Engenharia de Software I e II
* Qualidade de Software
* Arquitetura e Organização de Computadores
* Sistemas Operacionais
* Redes de Computadores I
* Sistemas Distribuídos
* Gestão de Projetos
* Governança e Gestão da Informação
* Empreendedorismo

Também são apresentadas algumas disciplinas optativas relacionadas às diferentes áreas.

## Possibilidades profissionais

O mapa apresenta possibilidades profissionais relacionadas à formação, como:

* Desenvolvedor de Software
* Analista de Dados / BI
* Inteligência Artificial / Dados
* Engenheiro de Software
* Redes / Infraestrutura
* Gestão e Sistemas de Informação
* Analista de Sistemas
* Administrador de Banco de Dados
* Segurança da Informação
* Testes / Qualidade de Software
* Arquiteto de Software
